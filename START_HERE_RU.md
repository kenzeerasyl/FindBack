# FindBack — с чего начать

## Запуск на Windows

1. Если ты получил архив `FindBack_Final_Updated.zip`, распакуй его в отдельную папку. В рабочей папке Codex используй `AI FUNDAMENTALS/FindBack`.
2. Внутри папки `FindBack` дважды нажми **Start FindBack.cmd**. Оставь открытым окно запуска.
3. Если вкладка не открылась автоматически, введи `http://127.0.0.1:8501/` в адресной строке браузера.

Лаунчер сначала ищет Python, установленный вместе с Codex, затем обычный Python. Для запуска на другом компьютере нужен Python 3.10 или новее. Дополнительные пакеты не нужны. Если порт 8501 занят, можно запустить `python -m findback.webapp --port 8502 --open` из папки проекта.

## Быстрая репетиция

1. Открой **Новый поиск → Открыть пример**. На карте увидишь путь до кафе. Во вкладке **Как это работает** покажи оценку действия `Q 43.014`.
2. Вернись в **Поиск** и нажми **Добавить подсказку**. Выбери **Библиотека** и оставь **Вещь могли видеть здесь**. Вероятность библиотеки вырастет с 40% до 84,21%. В истории раскрой **Показать расчёт Bayes**.
3. Нажми **Настроить проходы**. Перекрой клетки `(0, 8)` слева от библиотеки и `(1, 9)` под ней. Нажми **Готово**, затем выбери библиотеку. Интерфейс покажет, что маршрута нет. Вероятность для библиотеки останется 84,21%, а совет изменится на **Уточнить: Кафе**.
4. Нажми **Новый поиск**, введи «Наушники» и открой **Настройки симуляции**. Выбери режим **Симуляция**, сценарий **Обычный поиск**, бюджет 30, глубину 3 и seed 42. Оставь старт у главного входа и «Не помню» в поле последнего места. Нажми **Начать поиск → Выполнить действие**. Симуляция найдёт наушники в кафе и покажет 23 оставшиеся единицы времени.
5. Во вкладке **Как это работает** открой **Сравнение стратегий**. Там результаты 1 200 симуляций на учебной карте.

Для своего сценария введи название вещи и выбери старт и последнее известное место. На карте можно выбрать любое доступное место и записать результат проверки. Поиски и заметки доступны в **Мои поиски** после закрытия страницы при запуске с того же адреса и в том же браузере.

## Colab

Открой `FindBack_Demo.ipynb` через загрузку ноутбука в Google Colab. Выполни **Среда выполнения → Выполнить все**. Сам ноутбук содержит нужные модули и данные. Он показывает расчёт Bayes, маршрут A*, таблицу оценок по Беллману, результат симуляции и эксперименты. Сохранённые выводы также доступны без повторного запуска.

## Что сдавать
