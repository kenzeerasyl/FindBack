# Delivery checklist

## Part 1 — foundation (completed)

- Immutable, validated public models.
- Four fictional scenarios and portable JSON loader.
- A*, UCS and independent reference tests.
- Explainable Bayes and event ledger.
- Console demonstration and mathematical specification.

## Part 2 — sequential decisions and simulation (completed)

- Finite-depth belief-state Bellman planner, transparent Q-value branches.
- Budget, movement, stopping and terminal-state accounting.
- Simulator with private hidden truth and seeded randomness.
- Nearest-first and highest-belief-first comparison policies.
- Batch experiments, uncertainty summaries and exported results.
- Tests for information value, depth limits and no hidden-truth leakage.

## Part 3 — interactive application (completed)

- Local Python and browser application with map, route, belief bars and calculation tables.
- Scenario controls, manual evidence and seeded simulated search modes.
- Closure editing with validation, state reset, duplicate prevention.
- Decision explanations, Q-value comparison and downloadable history.
- End-to-end demonstration scenarios and browser verification.

## Part 4 — submission and defense (completed)

- Executed, portable Jupyter/Colab notebook covering all three methods.
- Runtime requirements and instructions for local launch and Colab.
- Results from actual batch execution, with interpretation and limitations.
- Team responsibilities, English defense questions and demonstration script.
- AI-use declaration and final packaging for LMS.

The final archive includes the source, notebook, experiment records, tests and
documentation for all four parts.
